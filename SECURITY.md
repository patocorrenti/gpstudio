# Security

If you find a security issue, please report it privately through GitHub:

**Security → Report a vulnerability**

(on this repository; enable [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) in repo settings if it is not on yet)

Please do not open a public issue, pull request, or bug-form report for security problems.

I'll review reports as best I can. There is no fixed response time.
