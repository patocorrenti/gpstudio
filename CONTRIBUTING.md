# Contributing

## Bug reports

Please report bugs with the [bug report form](https://forms.gle/PhvZEPBty96WWzDDA).

The email field is optional. If you leave one, I'll use it only to follow up on that report.

It will not be used for marketing, and it will not be shared with third parties for other purposes. The form is hosted by Google Forms, so Google processes the submission under their terms.
